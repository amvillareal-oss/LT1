# Project title: Calculating information about a garden based on its radius.
## Description: This program asks for the radius and calculates the area, circumference, square root of the calculated area, area rounded down, and the area rounded up of the garden.

## How to run 
- Enter the value of the radius
- All information will be calculated using math libraries
- The program will display the output

### Input needed
 - The radius of the circle

# Sample Output: 
###  Enter the radius of the garden in meters: 5
### Area of the garden: 78.54 square meters
### Circumference of the garden: 31.42 meters
### Square root of the area: 8.86 
### Area rounded down: 78 square meters
### Area rounded up: 79 square meters



##  Computational Thinking
- Problem identification: Calculate the area, circumference, square root of the calculated area, area rounded down, and the area rounded up of the garden.
- Problem decomposition: I asked the radius using inputs, then used math libraries to calculate, and used output to display the results.
- Pattern recognition: I realized that the formulas are quite similar to each other, and they all need the use of math libraries.
- Data representation: They are represented by numbers
- Algorithm Development: 

import math

input radius

compute area of a circle

compute circumference of a circle

compute the square root

compute the area rounded down to the nearest whole number

compute the area rounded up to the nearest whole number

output area of the circle in two decimal places

output circumference of the circle in two decimal places

output square root of the area in two decimal places

output rounded down area of the circle 

output rounded up area of the circle
